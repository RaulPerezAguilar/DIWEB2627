Ejercicio 3. ¿Qué estilo prevalece?
10 minutos
Disponemos de los siguientes archivos.
estilos.css:
h1 {
    color: blue;
    font-size: 30px;
}

p {
    color: black;
}
Documento HTML:
<head>
    <link rel="stylesheet" href="estilos.css">

    <style>
        h1 {
            color: green;
        }

        p {
            color: orange;
            font-size: 18px;
        }
    </style>
</head>

<body>

    <h1>Mi página web</h1>

    <p>Primer párrafo.</p>

    <p style="color: red;">Segundo párrafo.</p>

</body>
Cuestiones
¿De qué color aparece el título?
1. Verde (el estilo interno va después del externo).


¿Qué tamaño tiene el título?
2. 30px (solo lo define estilos.css).


¿De qué color aparece el primer párrafo?
3. Naranja (interno gana al externo).


¿De qué color aparece el segundo párrafo?
4. Rojo (el estilo en línea gana a todo).


Modifica el HTML para que el título aparezca en negro utilizando un estilo en línea.
5. <h1 style="color: black;">Mi página web</h1>


Elimina los estilos internos. ¿Qué sucede con los colores?
6. Solo quedan el externo y los en línea: título negro (en línea),
   primer párrafo negro (estilos.css), segundo párrafo rojo (en línea).
